### For Reading Assignments:


Keep your focus on the DIY section (to do it, the installation guide is at [https://cs3301.pages.dev/resources/xv6](https://cs3301.pages.dev/resources/xv6)) and the question given in the homework.

Use the book as a guide to see which parts of the code are performing significant functionality, and then look at the code on which they depend. This way, you can explore most of the codebase without reading it from one end to the other.

For example, 
in `kernel/proc.c`, `allocproc` provides the main functionality to allocate a new process on the system, which then depends on `allocpid`, so that way you read what allocpid does too.
