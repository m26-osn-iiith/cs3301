## Overview

The course project is a semester-long build where you design and implement a networked system from scratch. Projects must demonstrate mastery of at least two major course topics — for example, a multi-threaded server with proper concurrency control, or an OS component with a network-facing interface.

You will work **individually**. The project has three graded checkpoints: a proposal, a midpoint check-in, and a final submission with a live demo.

## Requirements

Your project must:

- Be written primarily in C
- Involve at least one thread synchronisation primitive (mutex, semaphore, or condition variable)
- Use the socket API for network communication
- Include a `Makefile` that builds cleanly with `make`
- Pass a basic test suite you define and document

## Proposal

Submit a one-page proposal (plain text or PDF) describing what you will build, which course topics it demonstrates, and a rough timeline with milestones. Proposals are due before the midterm. The instructor will respond within one week with approval or feedback.
